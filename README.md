# «21» — городская ОС

E-ink + пиксель-арт (EarthBound / Undertale). Карта, квесты, энциклопедия автономной
жизни, значки как у скаутов, краудфандинг, форум, админ-панель.

Стек: **Next.js + TypeScript + Tailwind + Zustand**. Данные — localStorage (заглушки).
Деплой — **GitHub Pages** (бесплатно), `output: 'export'`.

## Запуск

```bash
npm install
npm run assets   # генерация всех PNG в public/images (python3, без зависимостей)
npm run dev
```

## Деплой на GitHub Pages

1. Репозиторий → Settings → Pages → Source: **GitHub Actions**.
2. Пуш в `main` — workflow `.github/workflows/pages.yml` сам соберёт
   (`BASE_PATH=/имя-репозитория`) и выкатит `out/`.
3. Локально для Pages: `BASE_PATH=/repo npm run build`.

Ключи — в `.env.local` (не коммитится), пример в `.env.example`.
Если Яндекс Карты не поднялись — автоматически показывается пиксельная карта-заглушка.

## Механики

- **Энциклопедия**: 8 разделов открываются по порядку; следующая статья — после
  применения текущей (мини-квест). Прогресс в профиле.
- **Выживание**: 8 навыков, каждый = скаут-значок (свой PNG) + XP.
- **Внеклассное чтение**: 9 авторов, +3 кармы; все прочитаны = значок «Просвещённый».
- **Награды без слов**: иконки-PNG + числа. Значки и коллекционные айтемы — отдельные PNG.
- **Проблемы на карте**: любой может решить или поучаствовать в сборе (Tribute-ссылка).
- **Волонтёры** (уровень 2+): создают темы на форуме и добавляют проблемы на карту.
- **Админ** (`isAdmin`): проблемы, посты, статистика.
- **Telegram WebApp**: подключён `telegram-web-app.js`, `ready()/expand()`.

## Изображения

`scripts/gen_assets.py` рисует все PNG (1-bit, без внешних зависимостей):
значки, айтемы, маркеры, аватары, портреты, карту, сцену, стикер, QR.
Иконки и айтемы — только PNG, без SVG.
